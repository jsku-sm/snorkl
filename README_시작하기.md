# 구쌤 · 생각을 말해요

학생이 풀이를 쓰고, 그리고, 말하며 피드백을 받아 다시 도전하는 Streamlit 앱입니다.
Snorkl의 학습 흐름을 참고해 독립적으로 만든 앱이며, Snorkl 제품이나 Snorkl의 AI 엔진을 연결한 것은 아닙니다.

## 1. 구현된 다섯 가지 기능

| 기능 | 앱에서 사용하는 곳 |
|---|---|
| 교사 문제·모범 풀이·평가 기준 등록 및 학급 배정 | 교사 → 새 과제 만들기 |
| 학생의 글·화이트보드·풀이 사진·음성 설명 제출 | 학생 → 오늘의 과제 |
| AI의 잘한 점·관찰·힌트·추가 질문·기준별 평가 | 제출 후 또는 나의 기록 → AI 피드백 |
| 이전 설명 가져오기, 수정·성찰, 재제출 이력 | 학생 → 오늘의 과제 / 나의 기록 |
| 학생별 제출·첫 점수·최근 점수·오개념·교사 확인 | 교사 → 제출·분석 |

교사·학생 로그인, 교사 발급 학급 가입코드, 학생 비밀번호 변경, CSV 내보내기도 포함합니다.
학생은 자신의 기록만 보고, 교사는 전체 과제와 제출물을 볼 수 있습니다.

## 2. 지금 바로 체험하기

압축을 풀고, 이 README와 `app.py`가 있는 폴더를 VS Code에서 여세요.
터미널에서 아래 명령을 실행합니다. Mac에서 `python`이 없으면 `python3`를 사용하세요.

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

설정 파일이 없으면 **체험 모드**로 열립니다.

1. **학생으로 체험하기** → 원의 방정식 예제에 설명 입력 → **설명 제출하기**
2. 설명을 수정해 한 번 더 제출
3. 왼쪽 **교사로 전환** → **제출·분석** → 학생 풀이와 두 번의 시도 확인
4. 교사 판단·설명점수·피드백 저장 → 학생으로 전환해 교사 피드백 확인

체험 모드의 기록은 **현재 브라우저 세션에만** 있습니다. 페이지 새로고침, 접속 종료 또는 서버 재시작 시 사라질 수 있습니다. 실제 학생 정보는 체험 모드에 입력하지 마세요.

AI 키가 없으면 임의의 점수나 가짜 AI 피드백을 만들지 않습니다. 제출물은 저장되며 교사 피드백은 가능합니다. 음성 자동 전사와 AI 분석은 다음 설정 후 작동합니다.

## 3. GitHub에 올려 실제 운영하기

### A. 코드와 비공개 데이터 저장소

- **코드 저장소**: 압축 파일 자체가 아니라 압축을 푼 파일과 폴더를 올립니다. `app.py`, `think_app/`, `requirements.txt`가 같은 위치에 있어야 합니다.
- **데이터 저장소**: 별도의 GitHub **Private** 저장소를 만들고 README를 추가해 `main` 브랜치를 생성합니다.
- 데이터 저장소에만 접근하는 fine-grained token을 발급합니다. Repository permissions의 **Contents: Read and write**가 필요합니다.
- 기존 비공개 데이터 저장소를 사용할 수도 있습니다. 이 앱은 `think-learning-v1/` 경로만 사용하며 기존 대시보드의 파일을 읽거나 덮어쓰지 않습니다.

### B. 암호화키 생성

터미널에서 한 번 실행합니다.

```bash
python3 generate_key.py
```

출력된 키를 안전하게 보관하세요. **운영 데이터를 저장한 뒤 암호화키를 바꾸면 기존 기록을 읽을 수 없습니다.**

### C. Streamlit 배포 설정

1. Streamlit Community Cloud에서 코드 저장소를 연결합니다.
2. Main file path는 **`app.py`**로 지정합니다.
3. Python은 **3.11 또는 3.12**를 사용하세요. 이 패키지 검증 환경의 구체적인 버전은 `검증결과.md`에 적었습니다.
4. 앱 설정의 **Secrets**에 `secrets.toml.example`의 내용을 복사하고 모든 예시 값을 실제 값으로 바꿉니다.
5. `THINK_MODE = "github"`로 설정합니다.
6. 앱 접근 범위는 학교 운영에 맞게 비공개로 설정합니다. Streamlit의 앱 접근 권한과 앱 안의 교사·학생 로그인은 별도입니다.

실제 키나 토큰이 들어간 파일은 GitHub에 올리지 않습니다. 로컬 실행 시에는 `.streamlit/secrets.toml`에 넣습니다. 해당 파일은 `.gitignore`에 포함되어 있습니다.

필수 Secrets:

```toml
THINK_MODE = "github"
GITHUB_REPO = "본인아이디/비공개데이터저장소"
GITHUB_BRANCH = "main"
GITHUB_TOKEN = "발급한토큰"
ENCRYPTION_KEY = "generate_key.py에서출력된키"
THINK_TEACHER_ID = "teacher"
THINK_TEACHER_PASSWORD = "직접정한10자이상비밀번호"

AI_ENABLED = true
OPENAI_API_KEY = "본인의OpenAI_API키"
OPENAI_MODEL = "gpt-4.1-mini"
TRANSCRIPTION_MODEL = "gpt-4o-mini-transcribe"
```

AI를 나중에 연결하려면 `AI_ENABLED = false`로 두고 AI 관련 나머지 항목을 비워도 됩니다. API 사용료는 해당 API 계정에 발생하며, 모델 사용 권한과 결제·요청 한도는 계정에 따라 다릅니다.

### D. 교사와 학생의 첫 접속

1. 교사는 설정한 아이디와 비밀번호로 로그인합니다. 최초 실행 시 교사 계정이 한 번 생성됩니다.
2. **학급·학생**에서 학급 선택 → **가입코드 발급 / 재발급**
3. 학생은 **학생 가입**에서 학번·이름·학급·가입코드·비밀번호를 입력합니다.
4. 교사는 **새 과제 만들기**에서 과제를 학급에 배정합니다.
5. 학생이 풀이를 제출하면 교사의 **제출·분석** 화면에 표시됩니다. 필요한 경우 왼쪽 새로고침을 누릅니다.

가입코드는 재발급할 수 있으며, 기존 가입 학생의 계정에는 영향을 주지 않습니다.
교사 비밀번호를 바꾸려면 로그인 후 **내 계정**에서 변경하세요. 최초 설정 후 Secrets의 초기 비밀번호만 바꿔도 기존 계정 비밀번호가 바뀌지는 않습니다.

## 4. 학생 음성과 풀이판 사용법

- 풀이판은 펜·색·굵기·지우개·되돌리기·좌표 격자를 지원합니다.
- 터치펜·손가락·마우스 입력을 위한 Pointer Events로 만들었습니다. 실제 iPad Safari·Apple Pencil 기기 검증은 아직 하지 않았습니다.
- 선을 그린 후 **풀이판 반영 완료**가 표시된 것을 확인하고 제출하세요.
- **이전 설명을 가져와 고쳐 쓰기**를 누르면 이전 텍스트·전사를 가져오고, 이전 이미지가 있으면 첫 이미지를 풀이판 배경으로 불러옵니다.
- 음성은 **2분 이내**로 녹음합니다. 마이크 권한을 허용해야 하며, 배포 환경은 HTTPS를 사용하세요.
- AI 사용을 선택하고 **녹음한 말을 글로 바꾸기** → 수학 기호와 숫자를 확인·수정 → 제출 순서로 진행합니다.
- 새로 녹음한 음성은 다시 전사해야 제출할 수 있습니다. AI 미연결 상태에서는 녹음을 지우고 설명을 직접 입력할 수 있습니다.
- **음성 원본과 필기 시간축 영상은 저장하지 않습니다.** 최종 풀이 이미지, 학생이 확인한 음성 전사, 글 설명, 성찰을 저장합니다. 음성·필기 동기화 재생 기능은 이 버전의 범위에 포함되지 않습니다.
- 이미지에는 학생 풀이만 담으세요. 업로드 이미지는 방향 보정·크기 조절·JPEG 변환으로 메타데이터를 제거합니다.

## 5. AI 피드백과 교사 확인

- 서버에서 OpenAI Responses API로 문제·모범 풀이·기준·학생 텍스트·풀이 이미지를 분석합니다.
- 학번, 이름, 로그인 정보, 다른 학생의 기록은 AI 요청에 포함하지 않습니다. 다만 학생이 설명이나 이미지 안에 직접 쓴 개인정보는 내용에 포함될 수 있습니다.
- 음성은 별도의 전사 API로 글로 바꾼 뒤, 학생이 확인한 전사를 피드백 분석에 사용합니다.
- 학생이 AI 피드백을 선택한 경우에만 제출 내용을 API에 보냅니다.
- 정답 판단과 설명점수(0~4)를 구분합니다. 읽기 어렵거나 판단이 불확실하면 점수를 보류하고 교사 확인을 요청하도록 설계했습니다.
- 점수는 형성평가용 잠정 결과입니다. 교사가 판단·점수·피드백을 입력하면 보고서에는 교사 결과가 우선 반영됩니다.
- 제출물 저장을 먼저 완료한 다음 AI를 호출합니다. AI 오류가 나도 풀이를 다시 제출할 필요 없이 **나의 기록 → AI 피드백 받기 / 다시 시도**를 사용할 수 있습니다.
- 중복 클릭 시 같은 제출을 다시 만들지 않으며, AI 동시 분석을 잠금으로 방지합니다. 제출물당 AI 호출은 최대 3회, 초안당 음성 변환은 최대 5회입니다.
- AI 미연결·오류·호출 한도 도달 시 교사가 직접 피드백할 수 있습니다.

## 6. 기존 대시보드에 메뉴로 추가하기

기존 대시보드 전체 소스는 이번 작업에 제공되지 않았으며, 확인한 R4 보관본은 `classroom/ui.py` 수정 파일만 포함했습니다. 따라서 기존 로그인·과제 데이터를 자동으로 병합하지 않습니다.

1. 기존 저장소 최상위에 이 패키지의 **`think_app/` 폴더**를 추가합니다.
2. 기존 `requirements.txt`에 이 패키지의 의존성을 병합합니다. 기존 앱 버전과 충돌하면 새 별도 앱으로 먼저 실행하세요.
3. `integration/90_생각을_말해요.py`를 기존 앱의 **`pages/90_생각을_말해요.py`**로 복사합니다.
4. 기존 앱 Secrets에 `THINK_MODE`, `THINK_TEACHER_ID`, `THINK_TEACHER_PASSWORD`, AI 설정을 추가합니다. GitHub 저장소·토큰·암호화키를 공유할 경우 기존 값을 보존하세요.
5. 기존 앱이 `st.navigation`으로 페이지를 직접 구성했다면, 위 파일을 그 페이지 목록에도 추가해야 합니다.

이 추가 페이지는 **독립 로그인**을 사용합니다. 기존 로그인 상태에 적힌 역할을 검증 없이 믿지 않도록 설계했습니다. 기존 학생 계정은 가입코드로 이 기능에 별도 등록해야 합니다. 완전한 계정 통합은 기존 인증 모듈과 전체 소스를 확인한 후 연결할 수 있습니다.

새 앱으로 시험할 때는 기존 `app.py`를 덮어쓰지 말고 새 저장소에서 실행하는 편이 안전합니다.

## 7. 저장 구조와 운영 범위

별도 데이터베이스는 사용하지 않습니다.

| 모드 | 저장 위치 | 용도 |
|---|---|---|
| demo | 브라우저에 연결된 서버 세션 메모리 | 기능 체험, 실제 학생 운영 금지 |
| local | 실행 컴퓨터의 `.think_data/` 암호화 파일 | 로컬 시험 운영 |
| github | Private 저장소의 `think-learning-v1/` | 소규모 학급 시범 운영 |

계정·과제·시도·피드백은 `state.enc`, 최종 풀이 이미지는 `images/*.enc`에 암호화 저장됩니다. 비밀번호는 별도 salt를 사용한 PBKDF2 해시입니다. 원본 음성을 데이터 저장소에 기록하지 않습니다.

GitHub 저장은 SHA 충돌 재시도로 동시 변경을 보존합니다. 다만 GitHub는 실시간 학습 데이터베이스가 아니며 제출량·이미지·커밋 기록이 쌓이면 느려질 수 있습니다. 실제 25명 동시접속 성능을 보장하지 않습니다. 첫 수업 전에 몇 명으로 배포 환경 제출을 확인하세요. 네트워크 오류 시 로컬 임시 저장으로 몰래 전환하지 않습니다.

텍스트 상태 파일은 암호화 후 12MB까지로 제한했습니다. 이미지 크기는 장당 600KB 이하, 제출당 최대 2장입니다. 이 앱에는 전체 운영 기록 삭제·Git 이력 제거·데이터 이전 기능이 없습니다. 교사 화면의 CSV 내보내기로 학습 기록을 정리할 수 있지만, CSV는 이미지와 계정의 전체 복구용 백업은 아닙니다.

## 8. 자주 생기는 문제

| 증상 | 확인할 것 |
|---|---|
| 실행하니 체험 모드만 나옴 | Secrets에 `THINK_MODE = "github"` 설정 |
| 교사 로그인 실패 | `THINK_TEACHER_ID`와 처음 생성할 때의 비밀번호 확인. 5회 실패하면 5분 뒤 재시도 |
| 학생에게 과제가 안 보임 | 가입한 학급과 과제의 배정 학급이 같은지 확인 |
| AI 미연결 표시 | `AI_ENABLED = true`, 유효한 `OPENAI_API_KEY` 확인 |
| AI 호출 실패 | API 결제·모델 접근 권한·요청 한도 확인. 제출물은 보존됨 |
| 음성 변환 버튼을 누를 수 없음 | 녹음 완료, AI 연결, AI 사용 선택을 모두 확인 |
| GitHub 읽기·쓰기 오류 | Private 저장소, 초기 README/main 브랜치, 토큰 Contents 권한 확인 |
| 저장 데이터를 열지 못함 | 기존 ENCRYPTION_KEY를 유지했는지 확인 |
| 그림이 보이지 않음 | 풀이판 반영 메시지 확인 후 제출, 교사/나의 기록에서 ‘풀이 이미지 보기’ 선택 |
