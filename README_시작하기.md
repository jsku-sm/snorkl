# 구쌤 · 생각을 말해요

교사가 수업 활동을 만들고, 학생이 그래프·퀴즈·손글씨·음성으로 답안을 제출하는 Streamlit 앱입니다.

## 현재 앱: 수업 활동 대시보드

`streamlit_app.py` 또는 `app.py`를 실행하면 로그인 없이 수업을 관리할 수 있습니다. 첨부 디자인을 참고한 크림색 배경, 검은 테두리와 그림자, 라임·파랑·노랑 강조색을 사용합니다. 수업 이름·색상·참여 대상(1반~7반)을 수정하고, 학생에게 공유할 링크와 QR 코드를 만들 수 있습니다.

1. **수업 만들기**에서 수업 이름과 참여 학급을 입력합니다.
2. 수업 이름에 **데스모스** 또는 **Desmos**가 포함되면 이름을 눌렀을 때 현재 화면의 **작업하기**에 그래프 계산기가 바로 열립니다. 기존 그래프 활동이 있으면 그 활동을 사용하며, 없으면 기본 그래프 활동을 만듭니다.
3. **활동 관리**에서 문제·모범답안·평가 기준을 수정하거나 다른 모드의 활동을 추가합니다.
4. 수업 목록의 **공유**에서 링크 또는 QR 코드를 학생에게 전달합니다. 학생은 학번·이름·학급을 입력하고 **수업 참여하기**를 누릅니다. 수업의 **작업하기** 화면에서도 학생 정보를 입력해 바로 작성할 수 있습니다.
5. 학생이 답안을 제출하면 교사는 수업의 **학생 제출함**에서 학생별 시도, 그래프·풀이 이미지·녹음, 피드백을 확인합니다.

공유 화면의 학생 정보는 학생이 직접 입력합니다. 현재 대시보드는 교사·학생 로그인을 제공하지 않으므로 앱에 접근할 수 있는 사용자는 수업을 관리할 수 있습니다. 실제 운영에서는 앱 접근 범위를 제한하세요. 아래에 설명한 기존 로그인 기반 모듈의 가입코드·계정 기능과는 별개입니다.

## 활동 모드와 작업 저장

| 모드 | 학생 활동 | 저장되는 답안 |
|---|---|---|
| 데스모스 그래프 | 계산기에 수식·표 입력, 그래프 확대·이동 | 계산기 상태, 수식·표, 그래프 이미지 |
| 퀴즈 | 객관식 선택 또는 단답형 입력 | 선택한 답 또는 입력한 답, 설명 |
| 직접 쓰며 풀기 | 펜·지우개로 손글씨 풀이, 이미지 첨부 | 최종 풀이 이미지, 글 설명 |

**활동 추가하기**에서 모드를 선택합니다. 활동 이름에 `데스모스` 또는 `Desmos`가 포함되면 그래프 모드로 저장됩니다. 퀴즈는 선택지를 한 줄에 하나씩 2~8개 입력하면 객관식이며, 비우면 단답형입니다. 정답과 판단 기준은 모범답안·평가 기준에 입력합니다. 활동을 **진행 중**으로 설정하고 시작일·마감일·최대 시도 횟수를 확인하세요.

**모범답안 가져오기 · 파일 / 웹 검색**에서 TXT·MD·텍스트 PDF·DOCX를 올리고 **파일 내용 읽기**를 누릅니다. PNG·JPG 이미지 읽기와 웹 검색은 교사의 AI 연결이 필요합니다. **웹 검색**에서 문제나 검색어를 입력하고 **웹에서 모범답안 찾기**를 누르면 출처가 있는 답안 초안을 가져옵니다. 가져온 풀이와 수식을 검토해 **모범답안에 적용**한 뒤 수정하고 **활동 저장**을 누르세요. 파일은 10MB, 답안은 10,000자까지 지원하며 HWP는 PDF나 DOCX로 변환합니다. 스캔 PDF는 필요한 쪽을 이미지로 저장해 읽습니다.

새 활동은 **마감일을 시작일과 동일하게**가 기본 선택입니다. 시작일을 바꾸면 마감일도 같은 날짜로 따라갑니다. 선택을 해제하면 다른 마감일을 지정하거나 비울 수 있습니다.

**문제 풀이 시간 · 분**에서 평가 시간을 미리 정합니다. 0분은 시간 제한 없음이며, 시간을 정한 활동은 교사 시작 전까지 제출을 기다립니다. 교사는 활동 목록이나 학생 제출함의 **수행평가 타이머**에서 **배포할 풀이 시간(분)**을 입력하고 **평가 시작 · 배포**를 눌러 시작할 수도 있습니다. 모든 학생에게 같은 종료시간을 적용하며, 학생 화면의 남은 시간이 2초마다 갱신됩니다. 시작 후 **남은 풀이 시간(분) → 남은 시간 적용**으로 시간을 늘리거나 줄일 수 있습니다. 시간이 끝난 뒤에도 시간을 늘리면 다시 제출할 수 있으며, **평가 종료**로 명시적으로 종료한 평가는 재개하지 않습니다. 시간이 끝나면 서버에서도 제출을 차단하고, 작성 중인 글·퀴즈 답·그래프는 유지하여 작업 파일로 저장할 수 있습니다.

데스모스는 연결키가 없어도 현재 화면에서 [공식 그래프 계산기](https://www.desmos.com/calculator)를 열어 사용할 수 있습니다. 이 경우 수식·설명을 **나의 답안**에 적고 제출할 그래프를 화면 캡처해 첨부합니다. 외부 계산기 화면의 상태를 앱에서 자동으로 읽거나 저장하지는 못합니다.

**캡처하기 → 브라우저에서 현재 탭 선택·공유 → 그래프 영역 드래그 → 선택 영역 저장** 순서로 원하는 부분을 PNG 파일로 내려받습니다. 역방향 드래그, 다시 선택, 전체 선택, 취소를 지원합니다. 화면을 정지 이미지로 받은 직후 공유를 종료하며, 캡처 도중 계산기의 수식은 유지됩니다. 캡처 버튼은 API 키 없이도 사용할 수 있습니다. 화면 선택은 매번 브라우저에서 승인해야 하며, PC의 Chrome·Edge에서 HTTPS 또는 localhost로 실행합니다. 모바일·태블릿에서 화면 공유가 지원되지 않으면 기기 스크린샷으로 저장해 업로드합니다.

학번·이름을 입력한 뒤 **답안 이미지 첨부 · 최대 2개**에 저장된 PNG·JPG를 올리면 답안 제출 전에도 파일을 보관합니다. GitHub 모드에서는 `jsku-sm/class-dashboard-data`에 원본 바이트와 제출용 JPEG, 학생·활동별 파일 정보를 암호화 저장합니다. **답안에 첨부할 저장 파일 · 최대 2개**에서 첨부할 파일을 선택하고 **답안 제출**을 누르면 저장된 이미지가 답안에 연결됩니다. 이미지만으로도 그래프 답안을 제출할 수 있습니다. 원본 파일을 다시 내려받을 수 있고, 중복 업로드는 같은 파일을 재사용합니다. 저장 실패 시 파일을 유지한 채 **파일 저장 다시 시도**를 누릅니다. 체험 모드의 임시 보관은 GitHub 저장이 아니며 화면에서 구분하여 표시합니다.

그래프 상태·수식·이미지의 자동 저장에는 [공식 Graphing Calculator API](https://www.desmos.com/api/) v1.12를 사용합니다. [API 키 발급 페이지](https://www.desmos.com/my-api)에서 자신의 키를 발급하고 Streamlit Secrets 또는 환경변수에 `DESMOS_API_KEY`를 등록하세요. API 연결이 실패해도 현재 화면에서 공식 계산기를 열며 **연결 다시 시도**로 API 연결을 복구할 수 있습니다. 계산기를 사용하려면 실행 기기의 인터넷 연결이 필요합니다.

수식이나 그래프 범위를 변경한 뒤 **현재 수식과 그래프 반영 완료**를 확인하고 저장·제출합니다. 필요하면 **현재 그래프 반영**을 누릅니다. 저장되는 계산기 상태에는 수식·표와 그래프 범위가 포함됩니다. 그래프 이미지는 그래프 영역의 캡처이고 입력 패널의 수식은 별도 데이터로 보존합니다.

계산기의 **작업 파일 저장**은 미제출 그래프를 JSON으로 내려받습니다. 다시 접속했을 때 **작업 불러오기**로 이 파일을 가져오면 그래프를 이어서 편집할 수 있습니다. 교사 화면의 **그래프 상태 저장** 파일도 불러올 수 있습니다. 그래프 JSON에는 계산기 작업만 포함되며 글·녹음·첨부 이미지는 포함되지 않습니다.

**작업 전체 저장 → 작업 파일 준비 → 내 작업 ZIP 저장**은 글·전사·퀴즈 답이 있는 `작업.json`, `그래프.json`, 손글씨·첨부 풀이 JPG, 녹음 WAV를 묶어 내려받습니다. 파일은 **작업 파일 준비**를 누른 시점의 내용이므로 변경 후에는 다시 준비하세요. ZIP을 풀고 `그래프.json`을 **작업 불러오기**에 넣어 그래프를 이어서 편집할 수 있습니다. ZIP 전체를 앱에서 자동으로 복원하는 기능은 없습니다. 작업 파일 내려받기와 **답안 제출**은 별도 작업입니다. 브라우저의 임시 작성 상태만으로 서버 재시작 후 복원을 보장하지 않습니다.

모든 활동에서 **목소리로 설명하기**로 2분 이내 음성을 녹음할 수 있습니다. 마이크 권한을 허용하고 배포 앱은 HTTPS에서 사용하세요. 원본 WAV 녹음은 답안과 함께 저장되며 학생과 교사가 다시 재생할 수 있습니다. AI 연결 없이도 녹음과 답안 제출이 가능합니다. AI 피드백을 선택하면 녹음을 글로 변환해 분석하며, **녹음한 말을 글로 바꾸기**에서 전사 결과를 확인·수정할 수도 있습니다.

AI 피드백은 선택 기능입니다. `OPENAI_API_KEY`와 `AI_ENABLED = true`를 설정하고 학생이 **AI 피드백 받기**를 선택한 경우에만 답안을 AI에 보냅니다. 제출물 저장을 먼저 완료하므로 AI 오류가 나도 교사가 저장된 답안을 확인하고 피드백을 입력할 수 있습니다.

**내보내기** ZIP에는 실제 학생 시도의 CSV·JSON, 답안 이미지, 녹음 WAV, 그래프 상태 JSON이 포함됩니다. **학생으로 체험해보기**의 기록은 실제 학생 목록과 내보내기에서 제외됩니다.

## 학생별 GitHub 파일

`THINK_MODE = "github"`이면 각 제출을 비공개 GitHub 저장소의 학생별 폴더에 암호화한 개별 파일로 저장합니다.

```text
think-learning-v1/
  state.enc
  student-submissions/<수업 해시>/<학급 해시>/<학생 해시>/<제출 ID>-<내용 해시>.json.enc
  preview-submissions/…
  course-uploads/<수업 해시>/<학급 해시>/<학생 해시>/<업로드 ID>.json.enc
  preview-course-uploads/…
  images/<파일 ID>.enc
  course-archives/<보관 ID>.json.enc
```

학생 제출 파일은 해당 시점의 학생 정보·답안·전사·퀴즈 답·그래프 상태와 이미지·녹음 데이터를 포함하는 독립 JSON 묶음입니다. 파일명에는 학생 이름이나 학번 대신 식별자 해시를 사용합니다. 파일 내용은 `ENCRYPTION_KEY`로 암호화하므로 GitHub 웹 화면에서 바로 읽는 일반 JSON이 아닙니다. 교사 화면이나 ZIP 내보내기로 답안을 확인할 수 있습니다. 제출 이후 교사 피드백과 AI 결과는 공통 상태 파일에 기록됩니다.

업로드 원본 PNG·JPG와 답안용 JPEG는 `images/` 아래에 별도 암호화 파일로 저장하며, `course-uploads/`의 파일 정보가 두 파일을 연결합니다. 저장 위치는 위 Secrets의 `GITHUB_REPO`로 정하며 기본 대상은 `jsku-sm/class-dashboard-data`입니다. 이 저장소에 Contents 읽기·쓰기 권한이 있는 토큰과 기존 `ENCRYPTION_KEY`를 배포 환경에 설정해야 실제 업로드가 저장됩니다. 기존 데이터를 사용하는 경우 암호화키를 새로 생성하거나 바꾸지 마세요.

개별 제출 파일 저장이 실패하면 제출 완료로 처리하지 않습니다. 입력을 유지한 채 같은 버튼으로 다시 시도하세요. 이후 공통 상태 저장이 실패한 경우 준비된 파일이 남을 수 있으며, 재시도 시 같은 제출 ID를 사용합니다. 파일명에는 내용 해시도 포함하므로 서로 다른 내용이 같은 파일을 덮어쓰지 않습니다. 공통 상태의 `submission_file`이 가리키는 파일만 제출 완료된 답안으로 취급합니다. GitHub SHA 충돌은 재시도하여 동시 변경을 보존합니다.

수업을 **보관**하면 `course-archives/`에 수업 메타데이터를 암호화 저장하며 **보관됨**에서 다시 불러올 수 있습니다. 학생 제출 파일 저장과 수업 보관은 서로 다른 기능입니다.

## 기존 학습 모듈 (`think_app/ui.py`)

기존 로그인 기반 학습 화면은 `think_app/ui.py`의 `run()` 함수에 유지되어 있습니다. 현재 `app.py`와 `streamlit_app.py`는 같은 수업 관리 대시보드를 실행합니다. 이 문서에서 **기존 모듈**로 표시한 로그인·가입코드·음성 전사 안내는 `think_app/ui.py`에만 해당합니다.

## 기존 앱의 다섯 가지 기능

| 기능 | 앱에서 사용하는 곳 |
|---|---|
| 교사 문제·모범 풀이·평가 기준 등록 및 학급 배정 | 교사 → 새 과제 만들기 |
| 학생의 글·화이트보드·풀이 사진·음성 설명 제출 | 학생 → 오늘의 과제 |
| AI의 잘한 점·관찰·힌트·추가 질문·기준별 평가 | 제출 후 또는 나의 기록 → AI 피드백 |
| 이전 설명 가져오기, 수정·성찰, 재제출 이력 | 학생 → 오늘의 과제 / 나의 기록 |
| 학생별 제출·첫 점수·최근 점수·오개념·교사 확인 | 교사 → 제출·분석 |

교사·학생 로그인, 교사 발급 학급 가입코드, 학생 비밀번호 변경, CSV 내보내기도 포함합니다.
학생은 자신의 기록만 보고, 교사는 전체 과제와 제출물을 볼 수 있습니다.

## 앱 실행하기

압축을 풀고, 이 README와 `app.py`가 있는 폴더를 VS Code에서 여세요.
터미널에서 아래 명령을 실행합니다. Mac에서 `python`이 없으면 `python3`를 사용하세요.

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run streamlit_app.py
```

설정이 없으면 앱 프로세스 메모리에 데이터를 두는 체험 모드로 실행됩니다. 같은 앱 프로세스의 접속자는 이 체험 데이터를 공유하며 서버를 재시작하면 사라집니다. 지속 저장에는 `THINK_MODE = "local"` 또는 `"github"`를 사용하세요.

## 3. GitHub에 올려 실제 운영하기

### A. 코드와 비공개 데이터 저장소

- **코드 저장소**: 압축 파일 자체가 아니라 압축을 푼 파일과 폴더를 올립니다. `streamlit_app.py`, `think_app/`, `requirements.txt`가 같은 위치에 있어야 합니다.
- **데이터 저장소**: 별도의 GitHub **Private** 저장소를 만들고 README를 추가해 `main` 브랜치를 생성합니다.
- 데이터 저장소에만 접근하는 fine-grained token을 발급합니다. [GitHub Contents API](https://docs.github.com/en/rest/repos/contents)의 파일 생성·수정을 위해 Repository permissions의 **Contents: Read and write**가 필요합니다.
- 기존 비공개 데이터 저장소를 사용할 수도 있습니다. 이 앱은 `think-learning-v1/` 경로만 사용하며 기존 대시보드의 파일을 읽거나 덮어쓰지 않습니다.

### B. 암호화키 생성

터미널에서 한 번 실행합니다.

```bash
python3 generate_key.py
```

출력된 키를 안전하게 보관하세요. **운영 데이터를 저장한 뒤 암호화키를 바꾸면 기존 기록을 읽을 수 없습니다.**

### C. Streamlit 배포 설정

1. Streamlit Community Cloud에서 코드 저장소를 연결합니다.
2. Main file path는 **`streamlit_app.py`**로 지정합니다.
3. Python은 **3.11 또는 3.12**를 사용하세요. 이 패키지 검증 환경의 구체적인 버전은 `검증결과.md`에 적었습니다.
4. 앱 설정의 **Secrets**에 `secrets.toml.example`의 내용을 복사하고 모든 예시 값을 실제 값으로 바꿉니다.
5. `THINK_MODE = "github"`로 설정합니다.
6. 로그인 기능이 없으므로 앱 접근 범위를 학교 운영에 맞게 제한합니다.

실제 키나 토큰이 들어간 파일은 GitHub에 올리지 않습니다. 로컬 실행 시에는 `.streamlit/secrets.toml`에 넣습니다. 해당 파일은 `.gitignore`에 포함되어 있습니다.

GitHub 저장에 필요한 Secrets:

```toml
THINK_MODE = "github"
GITHUB_REPO = "jsku-sm/class-dashboard-data"
GITHUB_BRANCH = "main"
GITHUB_TOKEN = "발급한토큰"
ENCRYPTION_KEY = "generate_key.py에서출력된키"
```

데스모스 그래프를 자동 저장하려면 `DESMOS_API_KEY`를 추가합니다. AI 피드백·모범답안 웹 검색·이미지 읽기를 사용할 때 `AI_ENABLED = true`와 `OPENAI_API_KEY`를 설정합니다. 웹 검색을 사용하려면 `OPENAI_MODEL`에 웹 검색을 지원하는 모델을 지정합니다. `THINK_TEACHER_ID`·`THINK_TEACHER_PASSWORD`는 기존 로그인 기반 모듈용 설정입니다.

GitHub 보관 파일은 같은 비공개 저장소 안의 `think-learning-v1/course-archives/`에 따로 저장됩니다. 파일 내용은 `ENCRYPTION_KEY`로 암호화됩니다.

### D. 기존 로그인 기반 모듈의 첫 접속

1. 교사는 설정한 아이디와 비밀번호로 로그인합니다. 최초 실행 시 교사 계정이 한 번 생성됩니다.
2. **학급·학생**에서 학급 선택 → **가입코드 발급 / 재발급**
3. 학생은 **학생 가입**에서 학번·이름·학급·가입코드·비밀번호를 입력합니다.
4. 교사는 **새 과제 만들기**에서 과제를 학급에 배정합니다.
5. 학생이 풀이를 제출하면 교사의 **제출·분석** 화면에 표시됩니다. 필요한 경우 왼쪽 새로고침을 누릅니다.

가입코드는 재발급할 수 있으며, 기존 가입 학생의 계정에는 영향을 주지 않습니다.
교사 비밀번호를 바꾸려면 로그인 후 **내 계정**에서 변경하세요. 최초 설정 후 Secrets의 초기 비밀번호만 바꿔도 기존 계정 비밀번호가 바뀌지는 않습니다.

## 4. 기존 모듈의 학생 음성과 풀이판 사용법

- 풀이판은 펜·색·굵기·지우개·되돌리기·좌표 격자를 지원합니다.
- 터치펜·손가락·마우스 입력을 위한 Pointer Events로 만들었습니다. 실제 iPad Safari·Apple Pencil 기기 검증은 아직 하지 않았습니다.
- 선을 그린 후 **풀이판 반영 완료**가 표시된 것을 확인하고 제출하세요.
- **이전 설명을 가져와 고쳐 쓰기**를 누르면 이전 텍스트·전사를 가져오고, 이전 이미지가 있으면 첫 이미지를 풀이판 배경으로 불러옵니다.
- 음성은 **2분 이내**로 녹음합니다. 마이크 권한을 허용해야 하며, 배포 환경은 HTTPS를 사용하세요.
- AI 사용을 선택하고 **녹음한 말을 글로 바꾸기** → 수학 기호와 숫자를 확인·수정 → 제출 순서로 진행합니다.
- 새로 녹음한 음성은 다시 전사해야 제출할 수 있습니다. AI 미연결 상태에서는 녹음을 지우고 설명을 직접 입력할 수 있습니다.
- **음성 원본과 필기 시간축 영상은 저장하지 않습니다.** 최종 풀이 이미지, 학생이 확인한 음성 전사, 글 설명, 성찰을 저장합니다. 음성·필기 동기화 재생 기능은 이 버전의 범위에 포함되지 않습니다.
- 이미지에는 학생 풀이만 담으세요. 업로드 이미지는 방향 보정·크기 조절·JPEG 변환으로 메타데이터를 제거합니다.

## 5. 기존 모듈의 AI 피드백과 교사 확인

- 서버에서 OpenAI Responses API로 문제·모범 풀이·기준·학생 텍스트·풀이 이미지를 분석합니다.
- 학번, 이름, 로그인 정보, 다른 학생의 기록은 AI 요청에 포함하지 않습니다. 다만 학생이 설명이나 이미지 안에 직접 쓴 개인정보는 내용에 포함될 수 있습니다.
- 음성은 별도의 전사 API로 글로 바꾼 뒤, 학생이 확인한 전사를 피드백 분석에 사용합니다.
- 학생이 AI 피드백을 선택한 경우에만 제출 내용을 API에 보냅니다.
- 정답 판단과 설명점수(0~4)를 구분합니다. 읽기 어렵거나 판단이 불확실하면 점수를 보류하고 교사 확인을 요청하도록 설계했습니다.
- 점수는 형성평가용 잠정 결과입니다. 교사가 판단·점수·피드백을 입력하면 보고서에는 교사 결과가 우선 반영됩니다.
- 제출물 저장을 먼저 완료한 다음 AI를 호출합니다. AI 오류가 나도 풀이를 다시 제출할 필요 없이 **나의 기록 → AI 피드백 받기 / 다시 시도**를 사용할 수 있습니다.
- 중복 클릭 시 같은 제출을 다시 만들지 않으며, AI 동시 분석을 잠금으로 방지합니다. 제출물당 AI 호출은 최대 3회, 초안당 음성 변환은 최대 5회입니다.
- AI 미연결·오류·호출 한도 도달 시 교사가 직접 피드백할 수 있습니다.

## 6. 기존 로그인 기반 모듈을 대시보드에 추가하기

기존 대시보드 전체 소스는 이번 작업에 제공되지 않았으며, 확인한 R4 보관본은 `classroom/ui.py` 수정 파일만 포함했습니다. 따라서 기존 로그인·과제 데이터를 자동으로 병합하지 않습니다.

1. 기존 저장소 최상위에 이 패키지의 **`think_app/` 폴더**를 추가합니다.
2. 기존 `requirements.txt`에 이 패키지의 의존성을 병합합니다. 기존 앱 버전과 충돌하면 새 별도 앱으로 먼저 실행하세요.
3. `integration/90_생각을_말해요.py`를 기존 앱의 **`pages/90_생각을_말해요.py`**로 복사합니다.
4. 기존 앱 Secrets에 `THINK_MODE`, `THINK_TEACHER_ID`, `THINK_TEACHER_PASSWORD`, AI 설정을 추가합니다. GitHub 저장소·토큰·암호화키를 공유할 경우 기존 값을 보존하세요.
5. 기존 앱이 `st.navigation`으로 페이지를 직접 구성했다면, 위 파일을 그 페이지 목록에도 추가해야 합니다.

이 추가 페이지는 **독립 로그인**을 사용합니다. 기존 로그인 상태에 적힌 역할을 검증 없이 믿지 않도록 설계했습니다. 기존 학생 계정은 가입코드로 이 기능에 별도 등록해야 합니다. 완전한 계정 통합은 기존 인증 모듈과 전체 소스를 확인한 후 연결할 수 있습니다.

새 앱으로 시험할 때는 기존 `app.py`를 덮어쓰지 말고 새 저장소에서 실행하는 편이 안전합니다.

## 7. 저장 구조와 운영 범위

별도 데이터베이스는 사용하지 않습니다.

| 모드 | 저장 위치 | 용도 |
|---|---|---|
| demo | 앱 프로세스 메모리 | 기능 체험 |
| local | 실행 컴퓨터의 `.think_data/` 암호화 파일 | 로컬 시험 운영 |
| github | Private 저장소의 `think-learning-v1/` | 소규모 학급 시범 운영 |

공통 운영 상태는 `state.enc`, 이미지·현재 대시보드의 녹음 파일은 `images/*.enc`에 암호화 저장됩니다. 현재 대시보드에서는 위의 학생별 제출 묶음도 함께 저장합니다. 기존 로그인 기반 모듈의 계정 비밀번호는 별도 salt를 사용한 PBKDF2 해시이며, 해당 모듈은 원본 음성을 보관하지 않습니다. 로컬 모드는 `.think_data/` 아래에 암호화 파일을 저장합니다.

GitHub 저장은 SHA 충돌 재시도로 동시 변경을 보존합니다. 다만 GitHub는 실시간 학습 데이터베이스가 아니며 제출량·이미지·커밋 기록이 쌓이면 느려질 수 있습니다. 실제 25명 동시접속 성능을 보장하지 않습니다. 첫 수업 전에 몇 명으로 배포 환경 제출을 확인하세요. 네트워크 오류 시 로컬 임시 저장으로 몰래 전환하지 않습니다.

텍스트 상태 파일은 암호화 후 12MB까지로 제한했습니다. 이미지 크기는 장당 600KB 이하, 제출당 최대 2장입니다. 이 앱에는 전체 운영 기록 삭제·Git 이력 제거·데이터 이전 기능이 없습니다. 교사 화면의 CSV 내보내기로 학습 기록을 정리할 수 있지만, CSV는 이미지와 계정의 전체 복구용 백업은 아닙니다.

## 8. 자주 생기는 문제

로그인·가입코드 관련 항목은 기존 로그인 기반 모듈에만 해당합니다. 현재 대시보드의 학생 참여는 공유 링크에서 진행합니다.

| 증상 | 확인할 것 |
|---|---|
| 실행하니 체험 모드만 나옴 | Secrets에 `THINK_MODE = "github"` 설정 |
| 교사 로그인 실패 | `THINK_TEACHER_ID`와 처음 생성할 때의 비밀번호 확인. 5회 실패하면 5분 뒤 재시도 |
| 학생에게 과제가 안 보임 | 가입한 학급과 과제의 배정 학급이 같은지 확인 |
| AI 미연결 표시 | `AI_ENABLED = true`, 유효한 `OPENAI_API_KEY` 확인 |
| AI 호출 실패 | API 결제·모델 접근 권한·요청 한도 확인. 제출물은 보존됨 |
| 음성 변환 버튼을 누를 수 없음 | 녹음 완료, AI 연결, AI 사용 선택을 모두 확인 |
| GitHub 읽기·쓰기 오류 | Private 저장소, 초기 README/main 브랜치, 토큰 Contents 권한 확인 |
| 저장 데이터를 열지 못함 | 기존 ENCRYPTION_KEY를 유지했는지 확인 |
| 그림이 보이지 않음 | 풀이판 반영 메시지 확인 후 제출, 교사/나의 기록에서 ‘풀이 이미지 보기’ 선택 |
